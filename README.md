# W'orc out

**Level up your character *and* yourself!** W'orc out pops up an animated coach (orc or night elf) asking for push-ups, squats, burpees and more whenever you level up, kill mobs or bosses, run, die… Fully configurable, with a combat-safe timer, stats and streaks, plus optional group-break and guild-share messages.

## Commands
- `/wo` — settings
- `/wo test` — start a workout now
- `/wo toggle` — pause / resume

## Release
Push a tag like `v1.0.0`: the GitHub Action packages `WorcOut-<version>.zip`, publishes the GitHub Release, and uploads to CurseForge once the `CF_API_KEY` secret is set and `## X-Curse-Project-ID` is in the `.toc`.
